# Kalkulator Bantuan Am Persekolahan

Aplikasi web untuk mengunjurkan bilangan penerima dan peruntukan Bantuan Am Persekolahan bagi Kuala Lumpur, Labuan dan Putrajaya.

## Fungsi utama

- Pergerakan kohort automatik hingga tahap akhir yang layak.
- Laluan Tingkatan 1–5 diasingkan daripada Tingkatan 6 Bawah–Atas.
- Kadar bantuan boleh disunting mengikut tahun.
- Simpanan draf pada peranti serta sandaran JSON.
- Laporan Excel lima helaian.
- Sokongan luar talian selepas lawatan pertama.

## Pembangunan

```bash
npm install
npm run dev
```

Semakan penuh:

```bash
npm test
npm run lint
npm run build
```

GitHub Actions menerbitkan kandungan `dist` ke GitHub Pages selepas perubahan digabungkan ke cabang `main`.
